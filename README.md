## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager
- A modern web browser (for HTML examples)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/javascript-dsa.git
cd javascript-dsa
```

2. Install dependencies:
```bash
npm install
```

3. Open HTML files in your browser to view interactive examples

---

## 💻 Usage

### Running Examples
- **Browser:** Open any `.html` file in the `array/` directory with your browser
- **Node.js:** Execute script files directly using `node filename.js`

### Development
```bash
npm run dev
```
